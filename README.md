# catcha · 猫类身份验证

一个假装严肃的猫类身份验证小游戏。React + TypeScript + Vite，纯前端，无账号、API 或后端服务。所有场景插画使用原创 SVG / CSS，无外部图片或字体请求。

## 本地开发

需要 Node.js 22+。

```sh
npm ci
npm run dev
```

## 构建与测试

```sh
npm run build
npm test
```

浏览器测试默认使用本环境的 `/usr/bin/chromium`。其他机器可修改 `playwright.config.ts` 的 executablePath 或使用 Playwright 安装的 Chromium。

## 玩法

勾选“我不是人类”，依次通过纸箱、桌面整理、踩键盘、反复开门、忽略呼唤、饮水复核、捕猎、夜间跑酷、物品归属、日光调度、纸箱适配、猎物轨迹、无声潜行、监考接管和终审十五关。拖拽支持鼠标与触摸；键盘关也提供屏幕按键。错误操作使人类嫌疑增加 15%，达到 100% 会淘汰，需要重新验证。嫌疑值会随刷新保留。帮助按钮提供当前关提示。

进度条末端的线头可以拨动；第十五关累计拨动三次可触发隐藏结局。开场可填写最多 24 字的猫名，通关后显示在认证书上。可将证书保存为 1200×1500 PNG 图片。刷新恢复到当前关卡起点；“重新验证”清空本局进度。

设置支持静音和系统减少动态效果偏好。游戏进度仅保存在浏览器 localStorage 中。

桌面关：电脑、书本、水杯、手机和钢笔均可拖动，必须拖入下方地面区域再松开。也可聚焦物品后使用向下方向键移动、回车松爪。通过后仍可继续移动其他物品。办公关进入后直接接收实体键盘字符，不需要先点击虚拟键盘。

## 难度与提示

前四关提供明确帮助；第五、六关只给模糊审查备注；第七、八关在两次失误后仅开放一句有限提示；从第九关起没有帮助提示。捕猎关可以随时连续按住激光笔约 0.7 秒，无需先追逐红点；显示控制进度，中途松开需重按。点击「向工作人员报告设备故障」会增加 15% 人类嫌疑；夜间关的五步路线仅在起跑前显示；归属关需把三件物品都拖入「我的」区域。终审保留扒掉按钮及进度条隐藏结局。

第九关可选择「按失物招领流程归还物品」，每次使人类嫌疑增加 15%；达到 100% 会淘汰。申请不清除当前已认领物品，未淘汰时仍可继续完成归属复核。

## 第十至十四关

- 日光调度：打开窗帘，把暖斑拖到猫垫。空调申请会增加嫌疑。
- 纸箱适配：收耳、收尾、侧身后拖入窄箱。姿态错误或申请大箱会增加嫌疑。
- 猎物轨迹：同一条五步路线，去程正向记忆、返程逆向输入。错序会清空本段并自动恢复观察界面；调阅监控会增加嫌疑。
- 无声潜行：5×5 地图，按序经过三个气味点再到出口，不能踩玻璃或重复路径。走入死路可免费重置本关。
- 监考权限接管：拆保护盖、按爪痕顺序解锁、拖审核章覆盖驳回意见、归还控制台。错误口令或申请权限会增加嫌疑。

所有新关卡支持鼠标与触屏；拖拽物也支持方向键及回车操作。新关卡不提供帮助按钮，场景保留理解规则所必需的线索及操作反馈。终审与隐藏结局移至第十五关，证书仍支持自定义姓名及 PNG 保存。

## catcha 验证组件

主界面采用紧凑验证框、蓝色题目栏、方格选项和底部工具栏。保留十五关、姓名、证书 PNG 导出与嫌疑淘汰。

饮水关点击工作人员杯子一次即通过。夜间关准备界面不计时，点击开始后按真实经过时间进行 30 秒倒计时；超时只增加一次 15% 嫌疑，本轮可以重试；通过或离开本关会停止计时。凌晨 03:00 的房间时间与剩余时长分开显示。

第十二关去程为「羽毛 → 小鱼 → 老鼠 → 羽毛 → 小鱼」，返程严格为同一路线反向「小鱼 → 羽毛 → 老鼠 → 小鱼 → 羽毛」。路线在开始前显示，输入时显示已匹配进度。错误只重置本段；返程不会被重置到去程。

夜间巡视（第十三关）增加了三处水杯地块。进入水杯地块会碰倒水杯，暴露风险（共用人类嫌疑指标）增加 15%，达到 100% 淘汰。重复点击当前地块不重复处罚，重置路线不会清除风险；正常通关路线可完全避开水杯。
