# 猫联网 · 猫类身份验证

一个假装严肃的猫类身份验证小游戏。React + TypeScript + Vite，纯前端，无账号、API 或后端服务。所有场景插画使用原创 SVG / CSS，无外部图片或字体请求。

## 本地开发

需要 Node.js 22+。

```sh
npm ci
npm run dev
```

## 构建与测试

```sh
npm run build
npm test
```

浏览器测试默认使用本环境的 `/usr/bin/chromium`。其他机器可修改 `playwright.config.ts` 的 executablePath 或使用 Playwright 安装的 Chromium。

## 玩法

勾选“我不是人类”，依次通过纸箱、桌面整理、踩键盘、反复开门、忽略呼唤、饮水复核、捕猎、夜间跑酷、物品归属和终审十关。拖拽支持鼠标与触摸；键盘关也提供屏幕按键。错误操作使人类嫌疑增加 15%，达到 100% 会淘汰，需要重新验证。嫌疑值会随刷新保留。帮助按钮提供当前关提示。

进度条末端的线头可以拨动；第十关累计拨动三次可触发隐藏结局。开场可填写最多 24 字的猫名，通关后显示在认证书上。可将证书保存为 1200×1500 PNG 图片。刷新恢复到当前关卡起点；“重新验证”清空本局进度。

设置支持静音和系统减少动态效果偏好。游戏进度仅保存在浏览器 localStorage 中。

桌面关：电脑、书本、水杯、手机和钢笔均可拖动，必须拖入下方地面区域再松开。也可聚焦物品后使用向下方向键移动、回车松爪。通过后仍可继续移动其他物品。办公关进入后直接接收实体键盘字符，不需要先点击虚拟键盘。

## 难度与提示

前四关提供明确帮助；第五、六关只给模糊审查备注；第七、八关在两次失误后仅开放一句有限提示；第九、十关没有帮助提示。捕猎关需先追逐三次，再持续按住激光笔；夜间关的五步路线仅在起跑前显示；归属关需把三件物品都拖入「我的」区域。终审保留扒掉按钮及进度条隐藏结局。
